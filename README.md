# iDryer X

This repository contains documentation and related materials for the iDryer X project.

The main source of information for the project is the official iDryer documentation. The materials in this repository are used as a reference base for the design, assembly, and individual components of the device.

# Project

Dryer assembly options may vary significantly. iDryer can be built for one spool or for ten spools, in different enclosures, with various heating elements and different ways of providing the required convection.

The main principle remains the same: the iDryer dryer works equally effectively with all types of filament, is an energy-efficient solution with virtually no alternative in drying quality, does not overheat the filament, and keeps it in a ready-to-print condition.

If you are ready to spend time studying the documentation and building your own iDryer, this dryer will serve you for a long time, consistently providing high-quality drying.

## Repository Contents

- `docs/` — documentation for project versions and modules.
- `docs/img` — images, photos, and illustrations for the documentation.
- `CAD` — CAD models, drawings, and files for manufacturing parts.
- `PDF` — PDF files with cutting plans and additional materials.
