# Gehäuse aus EPP

Trocknungsgehäuse aus EPP (extrudiertes Polypropylen)

Polypropylen hat eine geringe Feuchtigkeitsaufnahme. Es ist durch gute elektroiusolierungseigenschaften in einem breiten Temperaturbereich gekennzeichnet.
Maximale Betriebstemperatur: 120 °C
Es gibt ein breites Sortiment an vorgefertigten Boxen verschiedener Größen auf dem Markt.
