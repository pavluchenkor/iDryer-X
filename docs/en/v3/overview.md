# iDryer V3

![iDryer](../../img/overview/iDryer.png){.img-left}

### Current Version

Key features:

* High level of readiness in the KIT version for self-assembly
* All parts are manufactured using industrial processes
* Complete KIT includes:

  * Milled PIR insulation body parts
  * Metal components for the base and spool holders
  * Printed circuit board (PCB)
  * Electronic components
  * Sensors
  * Fasteners
  * Aluminum tape and sealing foam for the door frame

[Visit Store](https://store.idryer.org/)

### Previous Versions

* Optimized for DIY assembly
* Open-source firmware
