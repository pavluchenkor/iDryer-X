# Spool Holder

![img](../../img/scale-module/IMG_8882-web.jpeg)

Designed for storing spools and tracking remaining filament, displaying the amount left on screen and signaling through a dedicated output.

## Printable Version

The top part of the module serves as a convenient alternative to existing spool holders.
It uses 694 bearings or equivalents (11x4x4) and a 4mm bronze rod from a hardware store as an axle.
Printed from composite ABS or any filament capable of withstanding the maximum drying temperature + 10-15°C.

You’ll need to purchase a [load cell module and HX711](https://aliexpress.ru/item/32860114708.html?sku_id=12000024686706530&spm=a2g2w.productlist.search_results.0.33494aa6rTvrLS)

Models can be easily adapted for available bearing sizes.

## Metal Versions

Several metal versions have been developed by community members.

### By @gungrel

A bent metal spool holder designed for 623 bearings. The base supports 1, 2, 3, or 4 spools. Aluminum tube 12x1mm is used as the roller.

### Remix [by @Kekht](https://t.me/Kekht)

*based on the earlier design [by @gungrel](https://t.me/gungrel)*

**Modifications:**

Max spool width - 83.6mm

Uses 686 bearings and aluminum tube - outer diameter 15mm, inner 13mm

Printed nylon anchors and M3 screws are used to secure bearings

Anchor hole diameter is 8mm; by changing only the anchors, any bearings or tubes can be used (max tube diameter 23mm)

Anchors are best printed from nylon (pure or composite). After removing screws, rollers detach easily

Side holes allow attaching supports for nonstandard spools (e.g., cardboard or samples)

A spacer for the load cell is included, allowing cable tie routing

Mounting holes for legs (two types) or custom printed brackets (also two variants for different screw types), enabling modular stacking

```
Bending setup:
Radius for 3mm steel - 2.7
Radius for 2mm steel - 1.8
Minimum flange - 14mm
K-factor - 0.44
```
