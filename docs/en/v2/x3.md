# iDryer x3 Filament Dryer

## Features

* Spool capacity: 3
* Drying temperature: up to 100°C
* Heater temperature control: yes
* Air temperature monitoring in chamber: yes
* Drying time: unlimited
* Forced ventilation: yes
* Filament weighing: yes
* Presets: yes
* Supported filament types: PLA, ABS, HIPS, PETG, SBS, Flex, PA6, PA12, PC, ABS, ASA, PP, POM, and others

!!! warning annotate "Important"

    All internal parts of the enclosure must be printed from materials that can withstand 100°C or higher.

    The air duct in the lower compartment must be insulated. The insulation solution used in the x3 project is provided for reference and can be reused as-is or replaced with any thermal insulation material. If not insulated, warm-up time will increase significantly and power consumption will rise.
