# iDryer V3

![iDryer](../../img/overview/iDryer.png){.img-left}

## Актуальная версия

### Отличительные особенности

- высокая степень готовности документации
- файлы для самостоятельной фрезеровки и лазерной резки
- высокая степень готовности KIT набора
- детали изготовлены промышленным способом
- полная комплектация набора включает:
    - фрезерованные детали корпуса из ПИР
    - металлические детали пола и катушкодержателей
    - печатаная плата
    - электронные компоненты
    - датчики
    - метизы
    - алюминиевый скотч и уплотнитель для портала двери

### Преимущества
- Максимально адаптированы для самостоятельной сборки
- Открытый [исходный код](https://github.com/pavluchenkor/iDryerController) прошивки
- Открытый [проект электроники](https://oshwlab.com/svet_team/idryer_copy_copy)
