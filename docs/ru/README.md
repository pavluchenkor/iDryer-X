## iDryerControllerV2

Новая версия основана на более мощном контроллере, поставляется в виде готовой печатной платы, изготовленной на производстве. Её не требуется собирать вручную. Контроллер предоставляет специализированные разъёмы упрощающие интеграцию дополнительной периферии.

## iDryerController

Поддержка платформы iDryerController продолжается, в основном, участниками сообщества.

Универсальное решение сушки филамента для энтузиастов 3D печати.
Можно собрать из чего-то доступного и дешевого, например старого нагревателя от хитблока, ненужного кулера и радиатора, а в качестве корпуса использовать коробку из хоз.мага и любой утеплитель. Список используемых деталей ограничен только фантазией.

Решения для энтузиастов в разделе DIY.

Так же доступен KIT набор, включающий все необходимое, включая готовые фрезерованные детали корпуса, электронику, металлические детали пола и катушкодержатели, нагреватель и вентилятор.
Инструкция по сборке KIT набора в разделе iDryer v3

## Функции

### Сушка
- выбор температуры и времени сушки
- точное поддержание выбранной температуры
- отображение текущей влажности
- автоматический переход в режим хранения

### Хранение
- поддержание установленной влажности
- автоматическое включение/выключение нагревательного элемента и конвекции при достижении заданной влажности
- длительность хранения не ограничена по времени

### Пресеты
- выбор пресета под часто используемые пластики
- установка температуры и времени для каждого пресета

### Взвешивание
- взвешивание филамента
- установка веса тары
- установка порога сигнала об окончании филамента
- сигнализация об окончании филамента (звуковой или триггерный выход)

### Проветривание камеры
- заслонка управляется сервомашинкой
- задание времени "открыто"
- задание времени "закрыто"

### Общая функциональность
- PID регулирование мощности нагревателя
- безопасное, для пластика, управление нагревательным элементом
- точное поддержание выбранной температуры
- контроль влажности в камере

### Энергоэффективность
- режим сушки ~ 40Вт/час
- режим хранение ~ 20Вт/час
- режим ожидание ~ 3Вт/час

## Прошивка
[файл прошивки](https://github.com/pavluchenkor/iDryerController/blob/master/src/Configuration.h) содержит все возможные варианты, настройка прошивки

### Прошивка для бутлоадера ардуино

!!! warning "Не рекомендуется"

  - нет WDT
  - нет поддержки серво
  - нет поддержки дополнительного ШИМ канала
  - не будет весов для катушек в сушилке
  - дальнейшая разработка не ведется

### Прошивка под ядро Minicore

  - работает watchdog timer / в случае cбоя перезагрузит прошивку
  - поддержка сервопривода
  - поддержка дополнительного канала шим
  - расширенное меню и функции
  - безопасность прошивки

>Прошивку для ядра ардуино использовать на ранних версиях можно, но не рекомендуется,лучше купить программатор, перешить бутлоадер и пользоваться безопасной прошивкой.
