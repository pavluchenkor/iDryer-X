# Перед сборкой

!!! warning "Подготовьте необходимые материалы и оборудование, проверьте комплектность набора."

## Материалы и оборудование

Для сборки устройства потребуется:

- Силиконовый герметик, предназначенный для высокотемпературных применений (например, каминный или автомобильный), обладающий хорошими клеящими свойствами для материалов на основе PIR-панелей.

- 3D-принтер и небольшое количество ABS-пластика для печати недостающих элементов корпуса.

- Компьютер с установленным Visual Studio Code и PlatformIO

- Программатор USBASP для прошивки управляющей платы на базе Arduino Nano.

- Паяльное оборудование, включая паяльник, припой, флюс, средства для очистки платы после пайки.

- Мультиметр для настройки напряжения питания.

- Стандартный набор инструментов, таких как отвертка, нож, кусачки, шуруповерт или дрель.

- Кримпер для обжима контактов и разъемов (при отсутствии можно обойтись подручными средствами, однако использование кримпера желательно для повышения качества соединений).

## Рекомендации по сборке

Ознакомьтесь с инструкцией, распечатайте необходимые детали.

Перед окончательной фиксацией любых компонентов обязательно предварительно приложите, примеряйте и проверьте их посадку и совместимость. Убедитесь, что все детали установлены правильно, что ничто не мешает их закреплению и дальнейшей сборке устройства. Только после полной проверки переходите к этапу окончательной фиксации и закрепления.

Если сборка затрагивает элементы электроники, все работы необходимо проводить на столе. На рабочей поверхности собираются все узлы: вентилятор, нагревательный элемент, подключаются датчики, дисплей, энкодер и другие элементы системы. После завершения сборки на столе проводится проверка работоспособности всех подключенных компонентов.

Такой подход позволяет избежать необходимости разбирать уже собранное устройство при обнаружении ошибок, а также делает процесс сборки более удобным, аккуратным и предсказуемым.
