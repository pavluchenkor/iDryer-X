# Инструкция по сборке контроллера r2.1

Выполняя простую последовательность действий, примерно через 40-60 минут можно получить полностью собранное устройство.
Из инструментов и принадлежностей потребуется:

- мультиметр
- паяльник
- припой
- паяльная паста/канифоль
- бокорезы/кусачки
- спирт для промывки платы после пайки
- маленькая щетка(например зубная) для промывки платы после пайки
- удобно иметь "третью руку" или тиски

!!! warning "Перед сборкой необходимо выставить напряжение 5.1В на выходе преобразователя MP1584 и перепаять резистор выбора частоты обновления на hx711"

!!! info "Гребенки"
    В текущем варианте сборки для соединения экрана и энкодера на плату запаиваются гребенки 4 и 5 пинов соответственно.
    Для соединения используются провода оконеченные с одной стороны разъемами BLS(Dupont/черные) которые запаиваются в энкодер и экран, при необходимости из энкодера можно выпаять гребенку установленную на заводе.

    Датчик BME280 паяется на провода идущие в комплекте набора, провод в датчик - разъем(белый) в плату
