# Changelog

Этот файл ведётся на русском языке и фиксирует заметные изменения в проекте iDryer X — корпусе, чертежах и документации сушилки.

## Типы изменений

- **Добавлено** — для новых функций.
- **Изменено** — для изменений в существующей функциональности.
- **Устарело** — для функций, которые скоро будут удалены.
- **Удалено** — для удалённых на данный момент функций.
- **Исправлено** — для любых исправлений багов.
- **Безопасность** — на случай уязвимостей.

## [3.0.0]

### Добавлено

- **Версия v3 доведена до состояния, по которому можно собирать.** Документация, файлы для фрезеровки и лазерной резки, комплектация со ссылками на заказ.
- **Набор KIT.** Фрезерованные панели корпуса из ПИР, металлические детали пола и катушкодержателей, плата, электроника, датчики и метизы. Компоненты выводные и крупные, паять удобно даже новичку.
- Открытый проект электроники: плату можно заказать самостоятельно.

### Изменено

- **Переход на iDryerControllerV2.** Готовая плата заводского изготовления, собирать вручную не нужно. С модулем связи добавляются портал и мобильное приложение. Версия v3 работает и с прежней платформой iDryerController.
- Документация переведена на несколько языков, навигация переработана.

## [2.x и ранее]

Ранние версии серии. Остаются в документации и по-прежнему рабочие: по ним собирают.
